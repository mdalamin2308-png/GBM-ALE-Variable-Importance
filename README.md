# GBM-ALE-Variable-Importance
# Gradient Boosting Regression Analysis

This repository contains a complete Python implementation of Gradient Boosting Machine (GBM) regression for environmental and engineering datasets.

## Features

- Gradient Boosting Regression
- Multi-target prediction
- Variable Importance analysis
- Accumulated Local Effects (ALE)
- Automatic polynomial model selection
- 95% Confidence Interval estimation
- Prediction performance (R² and RMSE)
- Publication-ready figures
- Excel and CSV result export

## Required Libraries

- pandas
- numpy
- matplotlib
- seaborn
- scikit-learn
- scipy
- openpyxl
- alibi (optional)

Install dependencies:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn scipy openpyxl alibi
```

## Input

- Excel dataset (`1.xlsx`)

## Outputs

- Combined Prediction Plot
- Variable Importance Plot
- ALE Plots
- Performance CSV
- ALE Summary CSV
- Excel workbook containing Variable Importance and ALE values

## Applications

- Environmental Engineering
- Water Quality Prediction
- Machine Learning
- Explainable AI (XAI)
- Civil Engineering Research
